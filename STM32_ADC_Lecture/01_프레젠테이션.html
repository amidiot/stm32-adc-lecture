01. HARDWARE

STM32란 무엇인가?

🔌

STM32 MCU

  • STMicroelectronics에서 개발한 32비트 ARM Cortex-M 기반 MCU 시리즈
  • 전 세계 시장 점유율 1위 및 산업 현장 표준(Standard) 채택
  • 누적 100억 개 이상 출하, 글로벌 양산 제품의 약 40% 점유
🏭

왜 STM32인가?

  • 실시간성(Real-time) - NVIC·DMA 기반 하드웨어 처리로 초저지연 제어 최적화
  • 확장성(Scalability) - 초저전력(L)부터 고성능(H)까지 1,000종 이상의 폭넓은 라인업
  • 생태계(Ecosystem) - CubeMX·HAL 라이브러리 제공을 통한 개발 기간 획기적 단축
  • 경제성(Cost-effective) - 칩 단위 공급을 통한 대량 양산 시 압도적 원가 절감
⚖️

플랫폼별 비교

  • Arduino - 교육 및 단순 프로토타입 제작용 (SW 기반 처리)
  • Raspberry Pi - 리눅스 기반 고사양 애플리케이션 및 데이터 처리용
  • STM32 - 산업용 정밀 제어 및 실제 양산 제품 구현용 (HW 기반 처리)
📱

주요 적용 분야

  • 모빌리티 - 자동차 전장, 드론, 퍼스널 모빌리티
  • 산업·의료 - 산업용 로봇, 공장 자동화, 정밀 의료기기
  • 가전·IoT - 스마트폰, 가전제품, 저전력 IoT 센서 노드

01. HARDWARE

정전식 토양 습도 센서의 원리

⚡

정전용량(Capacitance)이란?

두 개의 전극 사이에 전하를 저장할 수 있는 능력입니다.
전극 사이의 물질(유전체)이 다르면 저장할 수 있는 전하량도 달라집니다.

정전용량 공식
C = ε × (A / d)
C: 정전용량 (Farad)
ε: 유전율 (Permittivity)
A: 전극 면적
d: 전극 간 거리
🌊

토양 수분 감지 원리

  • 공기의 유전율: 약 1
  • 물의 유전율: 약 80
  • 토양에 수분이 많을수록 유전율이 증가
  • 유전율 증가 → 정전용량 증가 → 출력 전압 감소

01. HARDWARE

ADC란 무엇인가?

📊

Analog-to-Digital Converter

연속적인 아날로그 신호를 디지털 숫자로 변환하는 장치

🔢

12-bit 해상도

0 ~ 4095 (2¹² = 4096 단계)로 전압을 표현

⚡

기준 전압

NUCLEO-F401RE는 3.3V가 최대값 (ADC값 4095)

전압 계산 공식
전압(V) = ADC값 × (3.3V ÷ 4095)
예: ADC값 2048 → 2048 × 0.000806 = 1.65V

⚠️ 중요한 설정 값들

Resolution 12 bits (0~4095)
Scan Conversion Mode Disabled (단일 채널)
Continuous Conversion Disabled (폴링 방식)
03. 코드 작성

ADC 값 읽기

main.c의 while(1) 루프 안에 다음 코드를 추가합니다:

/* USER CODE BEGIN WHILE */ while (1) { // 1. ADC 변환 시작 HAL_ADC_Start(&hadc1); // 2. 변환 완료 대기 (타임아웃: 100ms) if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK) { // 3. ADC 값 읽기 (0 ~ 4095) uint32_t adc_value = HAL_ADC_GetValue(&hadc1); // 4. 전압으로 변환 float voltage = adc_value * 3.3f / 4095.0f; } // 5. ADC 정지 HAL_ADC_Stop(&hadc1); // 잠시 대기 HAL_Delay(500); } /* USER CODE END WHILE */
03. 코드 작성

수분량(%) 변환하기

🌱 센서 특성 이해

건조할수록 전압이 높음 (약 2.5V~3.0V)
습할수록 전압이 낮음 (약 1.2V~1.5V)

수분 퍼센트 계산
moisture(%) = (DRY - adc_value) ÷ (DRY - WET) × 100
// 센서 캘리브레이션 값 (실측 필요) #define ADC_DRY 3100 // 완전 건조 시 #define ADC_WET 1500 // 물에 담근 시 // 수분 퍼센트 계산 함수 int getMoisturePercent(uint32_t adc_value) { if (adc_value >= ADC_DRY) return 0; if (adc_value <= ADC_WET) return 100; return (ADC_DRY - adc_value) * 100 / (ADC_DRY - ADC_WET); }
03. 코드 작성

시리얼 모니터로 확인하기

NUCLEO 보드는 ST-LINK를 통해 USB 시리얼(UART2)을 지원합니다. printf로 값을 출력해봅시다.

// printf 리다이렉트를 위해 main.c 상단에 추가 #include <stdio.h> // _write 함수 오버라이드 (syscalls) int _write(int file, char *ptr, int len) { HAL_UART_Transmit(&huart2, (uint8_t*)ptr, len, HAL_MAX_DELAY); return len; } // while 루프 안에서 출력 printf("ADC: %lu, Voltage: %.2fV, Moisture: %d%%\r\n", adc_value, voltage, moisture_percent);

🔧 시리얼 터미널 설정

Baud Rate: 115200 | Data: 8 bit | Parity: None | Stop: 1 bit

04. 실습

전체 코드 예제 - 헤더 및 함수

/* USER CODE BEGIN Includes */ #include <stdio.h> /* USER CODE END Includes */ /* USER CODE BEGIN PD */ #define ADC_DRY 3100 #define ADC_WET 1500 /* USER CODE END PD */ /* USER CODE BEGIN 0 */ int _write(int file, char *ptr, int len) { HAL_UART_Transmit(&huart2, (uint8_t*)ptr, len, HAL_MAX_DELAY); return len; } int getMoisturePercent(uint32_t adc) { if (adc >= ADC_DRY) return 0; if (adc <= ADC_WET) return 100; return (ADC_DRY - adc) * 100 / (ADC_DRY - ADC_WET); } /* USER CODE END 0 */
04. 실습

전체 코드 예제 - 메인 루프

/* USER CODE BEGIN WHILE */ while (1) { HAL_ADC_Start(&hadc1); if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK) { uint32_t adc = HAL_ADC_GetValue(&hadc1); float voltage = adc * 3.3f / 4095.0f; int moisture = getMoisturePercent(adc); printf("ADC: %lu | %.2fV | Moisture: %d%%\r\n", adc, voltage, moisture); } HAL_ADC_Stop(&hadc1); HAL_Delay(1000); } /* USER CODE END WHILE */
04. 실습

센서 캘리브레이션

🏜️

건조 상태 측정 (ADC_DRY)

  • 센서를 공기 중에 놓기
  • 시리얼 모니터에서 ADC 값 확인
  • 보통 2800 ~ 3200 범위
  • 이 값을 ADC_DRY에 저장
💧

습윤 상태 측정 (ADC_WET)

  • 센서를 물에 담그기 (최대선까지)
  • 시리얼 모니터에서 ADC 값 확인
  • 보통 1200 ~ 1600 범위
  • 이 값을 ADC_WET에 저장
