3. STM32CubeIDE 프로젝트 생성

  1. STM32CubeIDE 실행
    메뉴: File → New → STM32 Project
  2. 보드 선택
    Board Selector 탭 클릭 → 검색창에 "NUCLEO-F401RE" 입력 → 선택 → Next
  3. 프로젝트 이름 입력
    Project Name: SoilMoistureSensor (또는 원하는 이름)
    Finish 클릭
  4. 기본 설정 유지
    "Initialize all peripherals with their default Mode?" → Yes 클릭

4. ADC 핀 설정 (CubeMX)

  1. .ioc 파일 열기
    프로젝트 탐색기에서 SoilMoistureSensor.ioc 더블클릭
  2. PA0 핀 설정
    Pinout view에서 PA0 핀 클릭 → ADC1_IN0 선택
  3. ADC 파라미터 확인
    좌측 Categories → Analog → ADC1 클릭
    Parameter Settings 탭에서 아래 값 확인:
파라미터 설정값 설명
Resolution 12 bits 0~4095 범위
Scan Conversion Mode Disabled 단일 채널 사용
Continuous Conversion Mode Disabled 폴링 방식
Discontinuous Conversion Mode Disabled -
  1. 코드 생성
    메뉴: Project → Generate Code (또는 Ctrl+Shift+G)

✅ UART2는 이미 설정됨

NUCLEO 보드 선택 시 ST-LINK 가상 COM 포트용 UART2가 자동으로 활성화됩니다. (PA2: TX, PA3: RX)

5. 코드 작성

5.1 헤더 추가

main.c 파일에서 /* USER CODE BEGIN Includes */ 섹션에 추가:

/* USER CODE BEGIN Includes */ #include <stdio.h> /* USER CODE END Includes */

5.2 매크로 정의

/* USER CODE BEGIN PD */ 섹션에 추가:

/* USER CODE BEGIN PD */ // 센서 캘리브레이션 값 (실측 후 조정 필요) #define ADC_DRY 3100 // 공기 중 (건조) #define ADC_WET 1500 // 물에 담근 상태 (습윤) /* USER CODE END PD */

5.3 함수 정의

/* USER CODE BEGIN 0 */ 섹션에 추가:

/* USER CODE BEGIN 0 */ // printf 리다이렉트 (시리얼 출력용) int _write(int file, char *ptr, int len) { HAL_UART_Transmit(&huart2, (uint8_t*)ptr, len, HAL_MAX_DELAY); return len; } // ADC 값을 수분 퍼센트로 변환 int getMoisturePercent(uint32_t adc_value) { if (adc_value >= ADC_DRY) return 0; if (adc_value <= ADC_WET) return 100; return (ADC_DRY - adc_value) * 100 / (ADC_DRY - ADC_WET); } /* USER CODE END 0 */

5.4 메인 루프

/* USER CODE BEGIN WHILE */ 섹션의 while 루프 안에 추가:

/* USER CODE BEGIN WHILE */ while (1) { // 1. ADC 변환 시작 HAL_ADC_Start(&hadc1); // 2. 변환 완료 대기 if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK) { // 3. ADC 값 읽기 (0 ~ 4095) uint32_t adc_value = HAL_ADC_GetValue(&hadc1); // 4. 전압 계산 (V) float voltage = adc_value * 3.3f / 4095.0f; // 5. 수분 퍼센트 계산 int moisture = getMoisturePercent(adc_value); // 6. 시리얼로 출력 printf("ADC: %4lu | Voltage: %.2fV | Moisture: %3d%%\r\n", adc_value, voltage, moisture); } // 7. ADC 정지 HAL_ADC_Stop(&hadc1); // 1초 대기 HAL_Delay(1000); /* USER CODE END WHILE */ }

8. 센서 캘리브레이션

📊 캘리브레이션이 필요한 이유

센서마다 특성이 조금씩 다르므로, 정확한 수분 측정을 위해 본인 센서의 건조/습윤 상태 ADC 값을 측정해야 합니다.

  1. 건조 상태 측정 (ADC_DRY)
    센서를 공기 중에 두고 ADC 값 확인 → 보통 2800~3200 사이
  2. 습윤 상태 측정 (ADC_WET)
    센서를 물에 담그고 ADC 값 확인 → 보통 1200~1600 사이
    ※ 침수선 넘지 않도록 주의!
  3. 코드 수정
    측정한 값으로 #define ADC_DRY와 #define ADC_WET 수정
  4. 재빌드 및 테스트
    다시 빌드 후 다양한 수분 상태에서 테스트

9. 문제 해결 (Troubleshooting)

증상 해결 방법
ADC 값이 0만 나옴 센서 연결 확인 (VCC, GND, AOUT)
PA0 핀 ADC1_IN0으로 설정되었는지 확인
ADC 값이 4095만 나옴 센서 VCC가 3.3V에 연결되었는지 확인
GND 연결 확인
시리얼 출력 안 됨 COM 포트 번호 확인
Baud Rate 115200 확인
_write 함수 추가되었는지 확인
빌드 에러 (undefined reference) stdio.h include 확인
huart2 변수가 main.c에 있는지 확인
값이 불안정하게 흔들림 HAL_Delay 시간 늘리기
여러 번 측정 후 평균값 사용
